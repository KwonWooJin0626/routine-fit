# ROUTINE FIT

질문 기반 맞춤형 건강 루틴과 주간·하루 계획을 제공하는 웹서비스입니다.

## 이전 진행 상태

기존 React + TypeScript 서비스를 GitHub와 Vercel로 이전하기 위해 준비한 저장소입니다.
현재는 이전 안내 문서만 등록되어 있으며, 실행 가능한 애플리케이션 소스와 배포는 아직 등록되지 않았습니다.

이전 시 기존 화면과 기능, 로그인, 계정별 데이터 저장을 유지합니다.
새 환경에서 검증이 끝날 때까지 기존 서비스는 변경하지 않습니다.

### 완료된 준비

- 공개 GitHub 저장소 생성 및 이전용 별도 작업 폴더 연결
- Vercel `routine-fit` 프로젝트 생성 및 로컬 프로젝트 연결
- 환경변수·인증정보·실제 사용자 데이터의 Git 제외 규칙 등록

### 다음 단계

로그인·DB 제공업체의 계정 처리 및 약관에 대한 소유자 승인 후 실제 운영 리소스를 구성합니다.
GitHub 변경에 따른 Vercel 자동 배포 연결은 앱 소스와 설정 검증 후 진행합니다.
기존 ChatGPT 로그인 계정과 새로운 인증 계정은 자동으로 동일인으로 간주하지 않으며,
기존 데이터 이전에는 별도의 소유자 확인과 계정 연결 검증이 필요합니다.

## 이전 검증 항목

- Vercel 배포 대상 계정·팀 및 프로젝트 접근 확인
- 로그인과 데이터베이스의 실제 운영 환경 구성
- 기존 계정과 새 로그인 계정의 안전한 연결 및 데이터 이전 검증
- React 화면·추천 로직·주간/하루 계획 기능 이전
- 인증·사용자 간 데이터 격리·동시 저장 충돌 방지 검증
- 테스트·빌드·미리보기 검증 후 운영 환경 전환

## 공개 저장소와 데이터 보호

소스 공개와 사용자 데이터 공개는 별개입니다.
비밀키, 인증 토큰, 환경변수 값, 실제 사용자 건강정보와 InBody 이미지는 이 저장소에 업로드하지 않습니다.
이전 데이터는 공개 Git 이력에 넣지 않고 별도로 처리합니다.

이 서비스는 생활 습관 관리를 위한 참고 정보를 제공하며 의료 진단·처방을 제공하지 않습니다.
