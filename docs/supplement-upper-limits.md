# 2025 KDRI 상한 비교

출처: 보건복지부·한국영양학회, 2025 한국인 영양소 섭취기준 요약표 xii–xviii.
사용자 제공 `2025 KDRI_요약표_국문_2025.12.29.pdf`의 표와 각주를 이미지로 대조했다.

공식 배포: https://www.kns.or.kr/fileroom/fileroom_view.asp?BoardID=Kdr&idx=167

## 적용

FDA DV의 95% 이상 색상 규칙을 제거하고, KDRI 상한(UL) 대비로 전환한다.
90% 미만 중립색, 90% 이상 100% 미만 주황, 100% 도달 주황 테두리, 초과 빨강.
90%는 제품 UI 안내선이며 의학적 또는 KDRI 판정 기준이 아니다.
상한 미만을 적정 복용량이나 안전성으로 해석하지 않는다. 복용 개수를 UL에 맞춰 변경하지 않는다.

기본은 개인 프로필을 추정하지 않는 19세 이상 성인 공통 참고 대상이다.
연령/성별에 따라 값이 달라지면 범위를 표시하고 비율 판정은 보류한다.
표의 선택자로 15–18, 19–29, 30–49, 50–64, 65–74, 75세 이상 / 성별 / 임신·수유를 지정한다.
이 설정은 현재 마운트된 화면에서만 유지하며 DB 개인 정보로 저장하지 않는다.
임신·수유는 성인 여성 행을 사용하고, 15–18세 임신·수유는 자동 비교 대상에서 제외한다.
요오드 임신·수유 상한은 미설정으로 유지한다.

## 성인 공통값

|영양소|상한/일|비교 조건|
|---|---|---|
|비타민 A|3000 μg RAE|레티놀 함량이 분리되지 않은 총 RAE는 판정 보류|
|비타민 C|2000 mg|전체 급원, 화면에는 영양제만 합산|
|비타민 D|100 μg|IU는 임의 환산하지 않음|
|비타민 E|540 mg α-TE|미국 라벨의 일반 mg와 동일시하지 않음|
|니아신|니코틴산 35 / 니코틴아미드 850 mg|현재 합계에는 형태별 함량 정보가 없어 판정 보류|
|비타민 B6|50 mg|75mg 제품은 실제 초과 표시 유지|
|폴릭산|1000 μg|DFE는 직접 비교하거나 일괄 환산하지 않음|
|마그네슘|350 mg|식품 외 급원 기준|
|철 / 아연|45 / 35 mg|전체 급원|
|구리 / 불소 / 망간|10 / 10 / 11 mg|구리 원문 10000 μg를 10mg로 환산|
|요오드 / 셀레늄|2400 / 400 μg|요오드 임신·수유 제외|

칼슘, 인, 콜린, 몰리브데넘은 연령·성별·생애주기에 따라 함수로 조회한다.
상한이 없는 비타민 B1/B2/B12, 단백질, 칼륨, 크로뮴 등에 DV 또는 임의 상한을 할당하지 않는다.
상한 미설정은 무제한 섭취 가능이라는 뜻이 아니다.

## 데이터 보존과 제한

제품 라벨, 복용량, 과거 실제 복용 스냅샷은 수정하지 않는다.
확인된 양의 상한 비율과 미확인 제품 경고는 독립적으로 표시한다.
식사·미등록 제품이 제외되므로 확인된 영양제만으로 상한 초과인지 검토하는 보조 표다.
A, 니아신, DFE 엽산의 형태별 UL 계산은 현재 미지원이며 회색 사유를 표시한다.
