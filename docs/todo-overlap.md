# To-do와 중복 일정

## 사용자 흐름

- 주간·하루 계획 오른쪽은 To-do / 블록 보관함 탭이다. 모바일은 시간표 / 할 일 화면을 전환한다.
- 기본 할 일 목록에는 완료 체크, 제목, 세부 설정 버튼만 표시한다. 제목+Enter로 추가한다.
- 세부 설정에서 카테고리, 마감일, 목록 날짜, 예상 소요 시간, 장소, 메모, 체크리스트와 기존 일정 연결을 조절한다.
- 시간 정하기에서 여러 날짜·시간대를 고르거나, 할 일을 시간표로 드래그한다. 드래그 이미지는 30분 칸 크기이며 놓인 일정은 예상 소요 시간(미입력 시 30분)을 제안한다.
- HTML drag/drop와 포인터/dragend 대체 경로를 지원한다. 내부 드래그만 처리하고 Escape·외부 영역·편집 금지 상태는 취소한다.
- 할 일 하나는 여러 일정에 연결할 수 있다. 한 일정 완료는 전체 할 일 완료로 전파하지 않는다. 필요하면 ‘할 일도 완료’를 직접 선택한다.

## 중복 처리

- `validatePlanner`와 `scheduleOverlapWarnings`는 안내 메시지다. 저장, 일괄 배치, 원본 수정, 가져오기, 전체 계획 생성은 시간 중복으로 실패하지 않는다.
- `validatePlannerErrors`, 스키마 및 `scheduleErrors`의 날짜·시간·연결 ID 같은 구조 검증과 리소스 제한은 유지한다.
- `calendarSegments`는 날짜·자정·일정 안의 휴식을 고려하여 활성 일정 구성원이 같은 구간을 만든다. 가로 분할 없이 전체 너비를 사용한다.
- 중복 구간만 진한 빨간 테두리와 모서리 개수를 표시한다. PC hover/focus는 메모 미리보기, 클릭/터치는 전체 목록 대화상자다. 각 일정 수정·체크는 독립적이다.
- 대화상자 내부의 포인터 이벤트가 시간표 드래그로 전달되지 않도록 한다.
- 새/수정 일정 저장 창의 경고는 변경 대상 일정과 관련된 충돌만 보여준다. 주간 요약에는 해당 주 전체 중복 구간을 표시한다.

## 데이터와 기록

- 선택적인 `planner.todos`에 최대 200개 할 일을 보관하고 `PlannerBlock.todoId`로 연결한다. 기존 데이터는 할 일 없이도 복원된다.
- 완료 체크는 상태·완료 시각만 저장하며 예상 시간을 실제 수행/XP로 환산하지 않는다. 실제 기록은 기존 일정 수행/강아지 API를 사용한다. 실제 시간 중복·연결·보상 검사는 유지한다.
- 할 일만 삭제하면 일정의 연결을 풀고, 연결 일정까지 삭제할 때도 실제 수행 기록은 보존한다. 계획표의 되돌리기로 복원할 수 있다.
- 블록 보관함 템플릿에는 todoId를 복사하지 않는다. 같은 양식을 재사용해 다른 일을 만들 때 기존 할 일에 잘못 연결되지 않도록 한다.
- 계획 점유 시간은 구간 합집합이다. 예상 부담은 겹친 구간의 최대 예상치를 시간 가중해 계산하며 의학적 측정값이 아니다. 분야별 시간은 각 분야 안에서 중복 제거하고 전체 합계와 별도로 설명한다.
