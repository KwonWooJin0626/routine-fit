# 분야별 질문·추천·중간 저장 설계

## 사용자 흐름
서비스 안내 → 루틴부터/일정부터 선택 → 관심 분야 최대 2개 → 한 분야 질문 → 해당 분야 저장 → 추천·이유·분량 피드백 → 홈으로 나가기 → 남은 분야 질문 이어하기.

기존 기초 설문은 재사용한다. 각 분야에서 목표 → 최근 활동 → 활동일 하루 시간 → 주간 목표 → 기본 질문 → 후보 3개씩 비교 → 선택 활동만 추가 질문 → 요일 → 실행 시점 → 확인 순서로 진행한다. 분야별 검증과 저장이 성공하기 전에는 결과 완료 화면으로 이동하지 않는다.

## 즉각적인 피드백
- 분야별 목표와 선택 이유, 실제로 생성한 오늘의 루틴, 오늘이 실행 요일이 아닐 때의 활동 예시를 구분한다.
- 운동 조정·보류 이유를 표시하고 설문 완료와 실천 완료를 구분한다. 완료 체크나 실제 시간을 자동 생성하지 않는다.
- 결과를 확인한 뒤 루틴으로 돌아간다. 다음 분야는 홈의 ‘독서 질문 이어하기’처럼 이름이 표시된 버튼으로 시작한다.

## 불편한 동작으로 진행이 막히던 문제
원인은 activityProfileSchema가 restriction != none 또는 경험 unknown을 저장 오류로 취급한 것이었다. 이를 아래처럼 분리한다.

1. 입력 검증: 선택지·요일·시간·저장 형식이 유효한가? 미입력·잘못된 조합만 오류로 처리한다.
2. 실행 추천 판단: 현재 활동이 사용자 제약과 충돌하는가? 조정 또는 보류 상태를 생성한다. 이 판단은 설문 저장이나 다음 분야 진입을 막지 않는다.

| 응답 | 처리 |
|---|---|
| 불편 없음 + 경험 확인 | 선택한 활동 제안 |
| 충격 회피 + 걷기/홈트 | 뛰기·점프 제외를 명시하는 방식 제안 |
| 충격 회피 + 러닝 등 충돌 | 운동 실행 추천 보류, 준비 활동 제안 |
| 무릎·손목·여러 불편·불확실성 | 선택 의향과 목표를 저장하고 실행만 보류 |
| 경험 미확인 | 준비 활동부터 제안, 설문 계속 가능 |

보류 시 준비물·장소 확인을 최대 5분의 별도 활동으로 표시한다. 통증 원인·재활 운동·안전성을 자동 판정하지 않는다. 실제 불편이 있으면 실행하지 않도록 안내하고 다른 활동을 비교할 수 있다.

## 기구 복수 선택
- equipment 질문에만 multiple 표시. mat,band 등 검증한 쉼표 구분 값으로 저장해 기존 단일 응답과 호환한다.
- none은 다른 기구와 배타적이다. 실제 기구를 고르면 none 해제, none을 고르면 실제 기구 해제.
- 서버에서도 중복·미등록 값·none+기구를 거절한다. 질문은 유효한 선택이 하나 이상 있을 때 다음으로 진행한다.

## 저장·복원
- checkpointActivity가 현재 확인한 프로필 하나만 병합한다. 다음 분야의 미확정 답변은 저장하지 않는다.
- answers.activities.pendingDomains/selectedDomains에 남은 분야와 선택 순서를 저장한다. 재로그인·새로고침 후 완료한 분야 대신 남은 첫 분야로 진입한다.
- 기존 프로필·실천 기록·수동 루틴·명시 입력한 실제 시간은 보존한다. 이전 비활성 분야 설정도 보관한다.
- 기존 인증 저장 API와 revision CAS를 사용한다. 저장 실패 시 현재 답변을 유지하고 재시도할 수 있다. JSON payload의 optional 필드이므로 DB 마이그레이션은 없다.

## 추천 시간과 기록
- 활동일 목표 5~120분, 주간 목표 최대 840분 또는 없음. 주간 목표를 선택 요일에 분배하며 하루 희망 상한·회당 5분에 맞지 않으면 사용자가 조정한다.
- 당일 새 루틴 예산은 5~240분이며 분야가 공유한다. 계획표 운동이 있으면 중복 시간을 추가하지 않고, 이동·준비시간도 확보한다.
- core에서도 계획표 빈 시간에 배치를 선택하면 가능한 시각을 안내한다. 주간 목표가 주간 시간표에 자동 삽입되는 것은 아니다.
- 목표·예정·실제 시간은 별도이다. 실제 시간 미입력은 null이며 예정 시간을 실적으로 복사하지 않는다.

## 화면 및 검증
- 서비스 소개·동의·기존 안내의 ‘성인용 서비스’ 문구 제거. 자료 제목의 대상 연령은 무작정 바꾸지 않는다.
- 질문: 한 화면에 하나의 결정. 결과: 핵심 요약을 먼저 보여주고 상세 이유는 펼치며, 나가기 버튼은 고정한다.
- 자동 테스트: scripts/test-engine.mjs. 개발 DB 체크포인트·복수 기구·진행 순서 왕복: scripts/test-activities-db.mjs. 전용 합성 행만 생성 후 정리한다.
