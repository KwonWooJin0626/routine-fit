# 생활패턴 시간·부담 차트

## 화면

- 생활패턴 분석에서 하루/주간, 날짜, 계획표/실제 수행 기준을 전환한다. 주간은 한국 시간 월요일~일요일이다.
- 파이차트 분모는 하루 1,440분 또는 주간 10,080분이다. 미등록/미기록을 회색으로 남기며 수면·휴식으로 추정하지 않는다.
- 조각 또는 범례를 누르면 그 카테고리의 활동명·시간·비율을 표시한다. 같은 카테고리의 같은 제목은 묶어서 합산한다. 주간에서는 해당 활동이 있는 날짜 수도 표시한다.
- `plannerHue`와 사용자 `planner.categoryColors`를 재사용한다. 파이는 카테고리 대표색(일정 테두리와 같은 hue/60%/54%)을 쓰며 개별 블록 채도는 사용하지 않는다.
- 실제 수면·여가·기타 기록에는 추가 대표색을 사용한다. 여러 카테고리에 연결된 하나의 실제 활동은 기록한 활동 종류로 분류한다.

## 정확한 시간 분할

`lib/lifestyle-charts.ts`는 각 날짜의 00:00~24:00을 모든 시작·종료 경계로 나눈다. 각 구간은 활동 0개면 미등록/미기록, 1개면 해당 카테고리, 2개 이상이면 겹친 시간으로 한 번만 센다. 서로 다른 활동 ID가 같은 카테고리에 있어도 겹침으로 표시한다. 겹침을 임의로 한 활동에 배분하지 않는다. 파이 모든 조각의 합계는 정확히 전체 기간이며 소수점 반올림한 비율은 100%와 소폭 다를 수 있다.

계획은 기존 `occurrencesInWindow`와 `activeOccurrenceSpans`를 사용하여 반복·제외일·종료일·야간과 등록된 내부 휴식 구간을 반영한다. 실제는 기존 PetDocument의 취소되지 않은 실제 수행 start/end/breaks를 사용한다. 여러 출처가 연결된 실행은 ID당 한 번만 집계하고 야간 활동은 해당 날짜에 분할한다. 완료 체크의 예정 시각을 실제 수행 시간으로 바꾸지 않는다.

## 스트레스·체력 부담

계획표에 직접 입력한 정신적 스트레스·육체적 피로도 1~5점의 시간 가중 평균이다. `Σ(구간 분 × 입력 점수) / 등록된 구간 분`으로 집계하며 겹친 구간은 각 항목의 최댓값을 사용한다. 미등록 구간은 평균에서 제외하고 값이 없으면 ‘—’로 표시한다. 별도의 건강 점수·생체 측정·소모 칼로리나 사모예드 능력치가 아니다.

하루는 4시간 단위 6구간, 주간은 요일별 7구간의 비교 막대로 표시한다. 4~5점 구간 시간도 함께 표시한다. 시간 파이가 실제 수행 기준이어도 부담 차트는 계획표 예상치 기준임을 화면에 명시한다.

## 검증·저장

기존 계정 데이터를 읽어서 계산하며 새 저장/API/DB 마이그레이션이 없다. 기록·색상 변경 시 React에서 다시 집계한다. SVG·범례는 키보드 선택과 접근성 이름을 지원하고 부담 차트에는 텍스트 상세를 제공한다.

`tests/growth.test.tsx`에서 하루/주간 총합, 겹침·동일 활동 중복·색상·반복 제외·야간·휴식·가중 평균·실제 수행/체크 구분·취소·다중 출처·SSR 접근성을 검증한다.
