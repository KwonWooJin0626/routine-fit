# 카테고리 색 계열

- 주간·하루 계획 → To-do/블록 보관함 상단 **카테고리 색상**에서 8개 카테고리를 각각 설정한다.
- 12개 색 계열과 카테고리 기본색을 선택할 수 있다. 각 행의 3개 샘플은 블록의 기존 강조 단계(은은하게/보통/선명하게)다.
- 저장 시 이미 등록한 모든 일정, 보관함, 하루 일정 목록, 블록 편집 미리보기, 겹침 목록의 카테고리 표시가 함께 바뀐다. 개별 블록을 다시 저장할 필요가 없다.
- 완료된 일정도 본래 카테고리 색을 유지하고, 체크·취소선으로 완료를 표시한다. 겹친 구간은 경고를 위한 빨간 테두리를 유지한다.
- 선택은 `planner.categoryColors`에 카테고리별 정수 hue(0–359)로 저장한다. 기존 계정은 이 필드 없이 기본색을 사용한다. 스케줄·수행 기록·성장 수치는 색 변경으로 수정하지 않는다.
- 색 선택은 모달 안에서만 미리보기 된다. 취소/닫기는 저장하지 않으며, ‘색상 저장’으로 적용한다. ‘모든 색 기본값으로’도 저장을 눌러야 반영된다. 기존 되돌리기와 계정 JSON 내보내기/가져오기에 포함된다.
- 검증: 타입 검사, 구·신규 데이터/잘못된 hue/완료된 블록의 표시 회귀 테스트, Clerk→API→Neon 저장·복원·초기화, 브라우저에서 완료 전후·계열 변경·취소·기본값 복원·모바일 확인.
