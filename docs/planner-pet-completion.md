# 일정 완료와 사모예드 성장 연결 · 2026-11-02

## 사용자 흐름

1. 오늘의 루틴에서 사모예드와 함께 시작한다. 선택 기능이며 기존 일정은 그대로 유지된다.
2. 일정/원본 블록의 ‘강아지와 함께 기록할 활동’을 정한다. 기본값은 카테고리 자동 매핑이다. 블록 카테고리와 다르게 지정해도 된다. 보관함·다중 배치·연결된 전체 수정에도 반영된다.
3. 주간 시간표 또는 하루 목록의 체크를 누른다. 주간 칸의 완료 버튼은 내용 수정 버튼과 분리되어 있다.
4. ‘예정대로 했어요’는 예정 구간을 실제로 수행했다는 명시적 확인이다. 종료 전에는 사용할 수 없으며 직접 실제 시각을 입력할 수 있다. 식사는 실제 식사량을 선택한다.
5. 일부 수행은 실제 분량/시각을 입력한다. ‘체크만 저장’도 가능하지만 실제 수행을 확인하기 전에는 게임 수치를 바꾸지 않는다.
6. 서버 저장 성공 시 완료 표시, 연결된 루틴, 강아지 상태, 노력 요약이 함께 갱신된다. 화면 아래 작은 행복 모션과 격려 문구를 보여준다. 애니메이션 줄이기/캐릭터 숨김 설정을 따른다.
7. 완료를 다시 누르면 취소한다. 하루 목록의 ‘수행 수정’에서 시각·활동을 고칠 수 있고, ‘미진행’으로 바꾸면 실제 수행 보상을 취소한다.

## 인정과 게임 상태

- 학업/자기계발/운동의 기존 XP와 일일 운동 상한을 유지한다.
- 업무·교류·여가·준비/생활 기록을 포함해 모든 새 실제 활동에 기쁨 반응을 준다. 편집, 같은 활동의 연결, 중복 재전송은 보상 모션을 다시 주지 않는다.
- 업무로 인한 게임 속 피로와 스트레스는 기존 규칙대로 계산하되, ‘해야 할 일을 해냈어요. 이제 잠깐 쉬어도 좋아요’라는 인정과 회복 안내를 함께 준다.
- 생활 활동은 실천 횟수로 인정한다. 운동·학습 XP를 임의로 추가하지 않는다.
- 포만감 감소율은 시간당 2를 유지한다. 계획을 등록했다고 자동 식사/수면을 인정하지 않는다.

## 실제 시간·중복·취소

- 기록은 `일정 ID + 발생 날짜`로 연결한다. 반복 일정의 다음 발생은 완료되지 않는다.
- 연결된 일정/루틴은 하나의 실제 수행에 여러 출처를 붙여 한 번만 반영한다.
- 일정 내부의 쉬는 시간은 절대 시각의 제외 구간으로 보관한다. 수행 구간, XP, 분야별 시간과 중복 검사에서 제외한다. 이 휴식 구간에는 별도 활동을 기록할 수 있다.
- 야간 일정의 종료/휴식 시각은 실제 다음 날짜로 계산한다. 미래 수행은 서버에서도 거절한다.
- 취소/미진행 변경은 기존 트랜잭션에서 연결된 표시와 게임 계산을 함께 되돌린다. 이미 취소된 오래된 기록이 나중의 수동 체크를 덮어쓰지 않는다.
- 실제 시간 수정 시 원래 시작·종료가 그대로면 제외한 쉬는 시간도 보존한다. 시각이나 분량을 바꾸면 쉬는 시간 없는 새 구간으로 바뀐다고 화면에 알린다. 여러 실제 구간은 나누어 기록한다.
- 90일 상세 기록 보관과 이전 성장 요약은 유지한다. 성장 초기화나 DB 스키마 마이그레이션이 없다.

## 나의 노력 요약

- 오늘의 루틴, 계획표, 주간 리포트에서 확인한 실천 횟수와 집중/운동/휴식/업무 시간을 표시한다.
- 완료와 일부 수행 모두 실제 기록으로 인정한다. 연결 출처 수는 활동 횟수에 더하지 않는다.
- 실천 횟수는 종료 날짜에 1회 집계하고, 야간 활동의 시간은 한국 날짜별로 나눈다. 취소하면 요약에서도 빠진다.
- 실제로 기록한 시간은 모두 보여주고, 강아지 XP는 함께 시작한 시각 이후만 계산한다. 두 범위를 확인창에서 구분한다.
- 최근 7일과 이전 7일의 기록일 수를 비교한다. 시작/보관 기간이 충분하지 않으면 2주 기록을 쌓는 중이라고 안내한다.
- ‘첫 실천’, ‘한 주에 3일 기록’, ‘집중과 쉼’ 표시는 실제 기록에서 계산한다. 실제 능력이나 건강이 향상되었다는 평가가 아니다. 미기록에 벌점이나 실패 표시는 없다.
